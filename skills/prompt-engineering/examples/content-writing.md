# 文章作成プロンプト例

## 1. ブログ記事作成

```markdown
# 役割
あなたはテクノロジー分野の専門ブロガーです。

# タスク
「リモートワークの生産性を高める5つのツール」というタイトルのブログ記事を書いてください。

## ターゲット読者
- スタートアップやテック企業で働くリモートワーカー
- 年齢: 25-40歳
- 技術リテラシー: 中〜高

## 要件
- 文字数: 2,000-2,500文字
- トーン: 専門的だがフレンドリー
- 構成:
  - 導入（リモートワークの課題）
  - 5つのツール紹介（各ツール400文字程度）
  - まとめと次のステップ
- 各ツールには以下を含める:
  - ツール名と概要
  - 主な機能
  - 料金プラン
  - 実際の使用例

## スタイルガイド
- 一文は60文字以内
- 箇条書きを活用
- 専門用語には簡単な説明を付ける
- 具体例を必ず含める

## SEO要件
- キーワード「リモートワーク 生産性」を5回使用
- H2見出しを5つ使用
- メタディスクリプション（150文字）も作成

## 期待する出力
1. 完全な記事本文
2. メタディスクリプション
3. 関連キーワード提案（5-10個）
```

## 2. ビジネスメール作成

```markdown
# 役割
あなたはプロフェッショナルなビジネスコミュニケーションの専門家です。

# タスク
プロジェクト遅延を顧客に報告するメールを作成してください。

## シチュエーション
- プロジェクト: Webサイトリニューアル
- 当初の納期: 2024年3月15日
- 新しい納期: 2024年4月5日（3週間遅延）
- 遅延理由: 
  1. クライアントからの追加要件（2週間）
  2. 技術的な問題（1週間）
- 顧客との関係: 長期取引先、重要顧客

## トーン
- 誠実でプロフェッショナル
- 謝罪を含むが、過度にへりくだらない
- 解決志向

## 構成
1. 件名（簡潔で明確）
2. 挨拶
3. 状況説明
4. 遅延の理由（責任を明確に）
5. 今後の計画
6. 追加の配慮（補償や特典があれば）
7. 結び

## 避けるべき要素
- 言い訳がましい表現
- 曖昧な表現
- 顧客への責任転嫁

## 期待する出力
1. 完全なメール文
2. 代替バージョン（よりフォーマル、よりカジュアル）
3. フォローアップメールの提案タイミング
```

## 3. ソーシャルメディア投稿

```markdown
# 役割
あなたはソーシャルメディアマーケティングの専門家です。

# タスク
新製品発表のためのソーシャルメディア投稿を作成してください。

## 製品情報
- 製品名: EcoBottle Pro
- 種類: 環境に優しいスマート水筒
- 主な機能:
  - 温度表示（デジタル）
  - 24時間保温/保冷
  - 飲水量トラッキング（アプリ連携）
  - リサイクル素材100%使用
- 価格: 9,800円
- 発売日: 2024年4月1日

## プラットフォーム別投稿
1. **Twitter/X** (280文字以内)
2. **Instagram** (キャプション + ハッシュタグ)
3. **LinkedIn** (プロフェッショナル向け)

## ターゲット
- 環境意識の高い20-40代
- アクティブライフスタイル
- テクノロジー愛好家

## トーン
- 熱意的
- 環境への配慮を強調
- 行動喚起（CTA）を含む

## 要件
- 各プラットフォームに適した長さとスタイル
- 絵文字を適切に使用
- ハッシュタグ戦略（10-15個）
- 投稿のベストタイミング提案

## 期待する出力
1. 各プラットフォームの投稿文
2. ハッシュタグリスト
3. 投稿スケジュール提案
4. エンゲージメント向上のヒント
```

## 4. プレスリリース

```markdown
# 役割
あなたは広報とメディアリレーションの専門家です。

# タスク
資金調達のプレスリリースを作成してください。

## 企業情報
- 企業名: TechFlow株式会社
- 事業内容: AIベースのワークフロー自動化SaaS
- 設立: 2022年
- 社員数: 25名

## 発表内容
- 調達額: 5億円（シリーズA）
- リード投資家: ABC Ventures
- その他投資家: XYZ Capital, エンジェル投資家3名
- 資金使途:
  1. プロダクト開発（AI機能強化）
  2. 営業・マーケティング強化
  3. 人材採用（エンジニア10名）

## 含めるべき要素
- 代表取締役のコメント
- リード投資家のコメント
- 市場機会と成長戦略
- 会社概要

## スタイル
- 標準的なプレスリリース形式
- 事実ベース、客観的
- 専門的だが読みやすい

## 文字数
- 本文: 600-800文字
- 会社概要: 100-150文字

## 期待する出力
1. 完全なプレスリリース（見出し含む）
2. メディアピッチ用の要約（100文字）
3. 想定Q&A（5問）
```

## 5. 製品説明文

```markdown
# 役割
あなたはeコマースのコピーライター専門家です。

# タスク
高級ワイヤレスイヤホンの商品説明文を作成してください。

## 製品スペック
- 製品名: SoundPure Elite
- 価格: 34,800円
- 主な機能:
  - アクティブノイズキャンセリング（ANC）
  - ハイレゾ対応
  - 連続再生時間: 8時間（ANCオン）
  - 急速充電対応（10分で2時間再生）
  - IPX5防水
  - 専用アプリでカスタマイズ可能

## ターゲット顧客
- オーディオファイル
- 通勤・通学者
- リモートワーカー
- 予算: 3-5万円

## トーン
- プレミアム感
- 技術的だが難解でない
- 感情に訴える（音楽体験の質）

## 構成
1. キャッチコピー（10-15文字）
2. リード文（50文字）
3. 主な特徴（箇条書き、5-7項目）
4. 詳細説明（300文字）
5. スペック表
6. 購入を後押しする一文

## 販売戦略
- 競合との差別化ポイントを強調
- 顧客の悩みを解決する価値提案
- 緊急性を作る（限定感なし、質で勝負）

## 期待する出力
1. 完全な商品ページ用説明文
2. 代替キャッチコピー（3パターン）
3. 検索キーワード提案
4. クロスセル商品提案
```

## 6. 技術文書（ユーザーマニュアル）

```markdown
# 役割
あなたはテクニカルライターです。

# タスク
スマートホームハブのクイックスタートガイドを作成してください。

## 製品
- 製品名: HomeHub 3000
- 機能: スマート家電の一元管理
- 対応デバイス: 照明、エアコン、カーテン、ドアロック

## 読者
- テクノロジーに詳しくない一般家庭
- 年齢層: 30-60代
- 初めてスマートホームを導入

## 構成
1. 同梱品の確認
2. 初期セットアップ（5-7ステップ）
3. 最初のデバイス登録（3-5ステップ）
4. 基本的な使い方（3つの主要機能）
5. トラブルシューティング（よくある3つの問題）

## スタイルガイド
- 一文は30文字以内
- 専門用語は最小限、使う場合は説明
- ステップは番号付き
- 各ステップに簡潔なビジュアル説明（テキストで記述）
- 肯定的で励ます表現

## ページ数
- A4サイズ、2-3ページ

## 期待する出力
1. 完全なクイックスタートガイド
2. 図版の説明（どんな画像が必要か）
3. よくある質問（FAQ）5問
4. カスタマーサポート連絡先の記載方法
```

---

これらの例は、ターゲット読者、トーン、構成を明確にすることで、目的に合った高品質な文章をAIから引き出すプロンプトの好例です。
