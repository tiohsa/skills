# プロンプトエンジニアリング クイックリファレンス

## よくあるユースケース別プロンプト

### 1. コードのバグを見つける

```
以下のコードにバグがあります。バグを特定し、修正案を提示してください：

[コードを貼り付け]

期待する動作: [正しい動作の説明]
実際の動作: [現在の問題]
```

### 2. コードを説明してもらう

```
以下のコードを初心者にもわかるように説明してください。
各部分の役割と、全体としての動作を説明してください：

[コードを貼り付け]
```

### 3. コードをリファクタリングする

```
以下のコードをリファクタリングしてください。
以下の観点で改善してください：
- 可読性
- パフォーマンス
- 保守性
- ベストプラクティスの適用

[コードを貼り付け]
```

### 4. 要約を作成する

```
以下の文章を[X]文字以内で要約してください。
重要なポイントを漏らさず、簡潔にまとめてください：

[文章を貼り付け]
```

### 5. アイデアをブレインストーミングする

```
[テーマ/問題]について、創造的なアイデアを10個提案してください。

制約:
- [制約1]
- [制約2]

各アイデアは1-2文で簡潔に説明してください。
```

### 6. テキストを書き直す

```
以下のテキストを[トーン: フォーマル/カジュアル/専門的など]な文体で書き直してください：

[元のテキスト]

ターゲット読者: [読者の特性]
```

### 7. エラーメッセージを解決する

```
以下のエラーメッセージが出ています。原因と解決策を教えてください：

エラーメッセージ:
[エラーメッセージを貼り付け]

環境:
- OS: [OS名]
- 言語/フレームワーク: [技術スタック]
- バージョン: [バージョン情報]

試したこと:
- [既に試した解決策]
```

### 8. SEO最適化されたコンテンツを作成する

```
以下のキーワードでSEO最適化された記事を作成してください：

メインキーワード: [キーワード]
関連キーワード: [キーワード1], [キーワード2], [キーワード3]

要件:
- 文字数: [X]文字
- 見出し構成: H2を3-5個使用
- メタディスクリプション: 150文字以内
- 自然な文章でキーワードを適切に配置
```

### 9. データを表形式にまとめる

```
以下の情報を表形式で整理してください：

[非構造化データや文章]

列: [必要な列名をリスト]
```

### 10. 専門用語を簡単に説明する

```
以下の専門用語を、専門知識のない[対象者: 例:中学生/一般の人など]にもわかるように
具体例を使って説明してください：

用語: [専門用語]
```

## プロンプト改善のチェックリスト（簡易版）

プロンプトを書いたら、以下を確認：

- [ ] **具体的か？** 曖昧な表現はないか
- [ ] **文脈があるか？** 背景情報を提供しているか
- [ ] **出力形式は明確か？** どんな形式で返してほしいか指定したか
- [ ] **制約は明示されているか？** 守ってほしいルールは書いたか
- [ ] **例はあるか？** 必要なら参考例を示したか

## よくある失敗と修正例

### ❌ 悪い例: 曖昧
```
マーケティング戦略を教えて
```

### ✅ 良い例: 具体的
```
B2C eコマースサイト（月間売上500万円、商品数200）向けに、
Instagram広告を中心としたマーケティング戦略を、
月間予算30万円、3ヶ月で売上20%増を目標として提案してください。

以下の情報を含めてください:
- 具体的な施策（3-5個）
- 各施策の予算配分
- 想定されるKPI
- 実行スケジュール
```

---

### ❌ 悪い例: 出力形式が不明確
```
Pythonで並び替えのコードを書いて
```

### ✅ 良い例: 出力形式が明確
```
Pythonでリストを並び替える関数を書いてください。

要件:
- 関数名: custom_sort
- 引数: リスト（整数）、並び替え方向（昇順/降順）
- 戻り値: 並び替え後のリスト
- アルゴリズム: クイックソートを使用

期待する出力:
1. 関数の実装コード
2. 使用例（3つのテストケース）
3. 時間計算量の説明
```

---

### ❌ 悪い例: 文脈がない
```
この戦略は良いですか？
```

### ✅ 良い例: 文脈がある
```
以下のコンテンツマーケティング戦略を評価してください：

[戦略の内容]

コンテキスト:
- 業界: BtoB SaaS
- 現状: ブログ月2本、SNS週1投稿
- 目標: 3ヶ月でリード100件獲得
- 予算: 月20万円

評価してほしい観点:
1. 実現可能性
2. 費用対効果
3. リソース配分の妥当性
4. 改善提案
```

## 高度なテクニックのクイックレファレンス

### Chain of Thought（段階的思考）
```
以下の問題を解決してください。ステップバイステップで考えてください：

問題: [問題文]
```

### Few-Shot（例を示す）
```
以下の例に従って、新しいケースを処理してください：

入力: [例1の入力] → 出力: [例1の出力]
入力: [例2の入力] → 出力: [例2の出力]

新しいケース:
入力: [新しい入力] → 出力: ?
```

### Multi-Perspective（複数視点）
```
以下の提案を3つの異なる視点から評価してください：
1. [視点1: 例:ビジネス観点]として
2. [視点2: 例:技術観点]として
3. [視点3: 例:ユーザー観点]として

提案: [提案内容]
```

### Self-Critique（自己批判）
```
[タスクの内容]

その後、あなたの回答を批判的に見直し、
改善点があれば修正版を提示してください。
```

## トラブルシューティング

### 出力が期待と違う場合

1. **より具体的に**: 詳細を追加する
2. **例を示す**: 期待する出力のサンプルを提供
3. **制約を追加**: 避けてほしいことを明示
4. **分割する**: 複雑なタスクを小さなステップに分ける

### 出力が長すぎる/短すぎる場合

```
[元のプロンプト]

出力の長さ: [具体的な文字数/段落数/項目数]
```

### 品質が低い場合

```
[元のプロンプト]

追加要件:
- 具体例を必ず3つ以上含める
- 各ポイントに根拠を添える
- プロフェッショナルな水準を保つ
```
