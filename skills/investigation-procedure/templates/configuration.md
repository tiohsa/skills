## 2. 調査項目

### 2.1 サーバー情報

```bash
# ホスト名
hostname

# OS情報
cat /etc/os-release
uname -a

# CPU
cat /proc/cpuinfo | grep "model name" | head -1
nproc

# メモリ
free -h

# ディスク
df -h
lsblk
```

**結果**:
| 項目 | 値 |
|------|-----|
| ホスト名 | |
| OS | |
| CPU | [コア数] |
| メモリ | [容量] |
| ディスク | [容量] |

### 2.2 ネットワーク情報

```bash
# IPアドレス
ip addr show

# ルーティング
ip route

# 開いているポート
ss -tlnp

# ファイアウォール (RHEL/CentOS)
firewall-cmd --list-all

# ファイアウォール (Ubuntu)
ufw status verbose
```

**結果**:
| インターフェース | IPアドレス | 用途 |
|----------------|-----------|------|
| | | |

| ポート | サービス | 状態 |
|--------|---------|------|
| | | |

### 2.3 ミドルウェア情報

#### Webサーバー
```bash
# Apache
httpd -v
apache2 -v

# Nginx
nginx -v
```

#### データベース
```bash
# MySQL/MariaDB
mysql --version

# PostgreSQL
psql --version
```

#### Java/アプリケーションサーバー
```bash
java -version
```

**結果**:
| ミドルウェア | バージョン | 設定ファイル |
|------------|-----------|-------------|
| | | |

### 2.4 サービス状態

```bash
# 稼働中サービス一覧
systemctl list-units --type=service --state=running

# 特定サービスの状態
systemctl status [service-name]

# 自動起動設定
systemctl is-enabled [service-name]
```

**結果**:
| サービス名 | 状態 | 自動起動 |
|-----------|------|---------|
| | 稼働中/停止 | 有効/無効 |
