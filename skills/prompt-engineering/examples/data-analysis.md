# データ分析プロンプト例

## 1. 売上データ分析

```markdown
# 役割
あなたはデータアナリストで、eコマースビジネスの専門家です。

# 与えられたデータ
以下は2024年1-3月の月別売上データです:

| 月 | 売上（円） | 注文数 | 平均注文額（円） | 新規顧客数 | リピート率 |
|----|-----------|--------|----------------|-----------|----------|
| 1月 | 15,000,000 | 1,200 | 12,500 | 450 | 37.5% |
| 2月 | 12,500,000 | 1,000 | 12,500 | 350 | 35.0% |
| 3月 | 18,000,000 | 1,500 | 12,000 | 550 | 36.7% |

# 分析タスク
以下の観点でデータを分析してください:

1. **トレンド分析**
   - 売上と注文数の推移
   - 新規顧客獲得の傾向

2. **パフォーマンス指標**
   - 月別成長率
   - 顧客あたりの価値（LTV推定）

3. **異常値・パターン**
   - 2月のパフォーマンス低下の要因仮説
   - リピート率の変動

4. **予測と提案**
   - 4月の売上予測（3パターン: 悲観・標準・楽観）
   - 改善のための3つの具体的施策

# 出力形式
1. **エグゼクティブサマリー** (150文字): 最重要ポイントを3つ
2. **詳細分析**: 各観点の分析結果
3. **ビジュアライゼーション提案**: どのチャートが適切か（折れ線、棒グラフ、円グラフなど）
4. **アクションアイテム**: 優先順位付きで5つ提案
5. **追加で必要なデータ**: さらに深い分析のために必要な情報
```

## 2. ユーザー行動分析

```markdown
# 役割
あなたはUXリサーチャーで、Webアプリのユーザー行動分析の専門家です。

# 与えられたデータ
Google Analyticsからのトラフィックデータ（2024年3月）:

- 総訪問者数: 50,000
- ページビュー: 180,000  
- 平均セッション時間: 3分20秒
- 直帰率: 55%
- コンバージョン率: 2.5%

主要ページの指標:
| ページ | 訪問数 | 平均滞在時間 | 離脱率 |
|--------|--------|------------|--------|
| トップページ | 20,000 | 1分30秒 | 65% |
| 製品一覧 | 15,000 | 4分00秒 | 45% |
| 製品詳細 | 8,000 | 5分30秒 | 35% |
| カート | 4,000 | 2分00秒 | 70% |
| 購入完了 | 1,250 | 30秒 | 5% |

# 分析タスク
以下の観点で分析してください:

1. **ファネル分析**
   - 各ステップのコンバージョン率
   - 最大の離脱ポイント

2. **ユーザージャーニー**
   - 典型的な訪問パターン
   - 成功したコンバージョンの経路

3. **問題点の特定**
   - カートの離脱率が高い理由の仮説（5つ）
   - トップページの直帰率改善方法

4. **セグメント分析**
   - デバイス別（モバイル vs デスクトップ）の行動差異の推測
   - 新規 vs リピーターの行動パターン

# 出力形式
1. **分析サマリー** (200文字)
2. **ファネルレポート**: 各ステージの詳細
3. **改善提案**: 
   - 短期施策（1ヶ月以内実装可能）: 3つ
   - 中期施策（3ヶ月）: 3つ
4. **A/Bテスト提案**: 優先度の高いテスト案3つ
5. **追加調査の提案**: ヒートマップ、ユーザーインタビューなど
```

## 3. 市場調査データ分析

```markdown
# 役割
あなたは市場調査とビジネスインテリジェンスの専門家です。

# 与えられたデータ
競合5社の市場シェアデータ（フィットネスアプリ市場、日本）:

| 企業 | 市場シェア | ユーザー数（万人） | 月額料金（円） | 主な機能 |
|------|-----------|------------------|--------------|---------|
| A社 | 35% | 350 | 980 | ワークアウト動画、食事管理 |
| B社 | 25% | 250 | 1,280 | パーソナルトレーニング、コミュニティ |
| C社 | 20% | 200 | 0（広告収益） | 基本ワークアウト |
| 自社 | 12% | 120 | 1,480 | AI食事提案、詳細分析 |
| D社 | 8% | 80 | 780 | シンプルなワークアウト |

# 分析タスク

1. **競争ポジション分析**
   - 価格帯別のセグメント
   - 機能による差別化ポイント
   - 自社の強みと弱み（SWOT分析簡易版）

2. **市場機会**
   - 未開拓セグメント
   - 成長余地の大きい領域

3. **戦略提案**
   - シェア拡大のための3つの戦略
   - 各戦略のリスクとベネフィット

4. **価格戦略**
   - 現行価格の妥当性評価
   - 価格変更シミュレーション（±200円の影響予測）

# 追加コンテキスト
- 市場全体は年間15%成長
- 自社の昨年比成長率は20%
- 主要ターゲット: 25-40歳の都市部在住者

# 出力形式
1. **市場概況サマリー** (200文字)
2. **4象限ポジショニングマップ** (テキストで記述)
3. **戦略提案**: 各戦略の詳細、実行ステップ、期待効果
4. **KPI提案**: 成功を測定する5つの指標
5. **リスク分析**: 想定されるリスクと対策
```

## 4. 財務データ分析

```markdown
# 役割
あなたは財務アナリストで、スタートアップの財務健全性を評価する専門家です。

# 与えられたデータ
SaaS企業の四半期財務データ（単位: 万円）:

**損益計算書（2024年Q1）**
- 売上高: 5,000
- 売上原価: 1,500
- 粗利益: 3,500
- 営業費用:
  - 人件費: 2,000
  - マーケティング: 1,200
  - その他: 500
- 営業利益: -200
- 純利益: -250

**その他の指標**
- MRR（月間経常収益）: 1,600万円
- ARR（年間経常収益）: 19,200万円
- CAC（顧客獲得コスト）: 50,000円
- LTV（顧客生涯価値）: 180,000円
- チャーンレート: 5%/月
- 従業員数: 25人

# 分析タスク

1. **財務健全性評価**
   - 粗利率、営業利益率の評価
   - バーンレート（月間消費額）の計算
   - ランウェイ（残資金での存続可能期間）の推定（現金残高2億円と仮定）

2. **SaaS指標分析**
   - LTV/CAC比率の評価
   - チャーンレートの深刻度
   - ユニットエコノミクスの健全性

3. **成長性分析**
   - 月次成長率（MoM）の推定
   - 黒字化までのロードマップ
   - ブレークイーブンポイント（損益分岐点）

4. **改善提案**
   - コスト最適化の3つの施策
   - 売上拡大の3つの施策
   - 優先順位とインパクト評価

# 出力形式
1. **財務健全性スコア** (10点満点、理由付き)
2. **詳細分析**: 各観点の評価とベンチマーク比較
3. **アクションプラン**: 優先順位付き改善施策
4. **シナリオ分析**: 
   - ベストケース: 月次成長率20%継続
   - ワーストケース: チャーンレート10%に悪化
5. **投資家向けサマリー** (300文字)
```

## 5. A/Bテスト結果分析

```markdown
# 役割
あなたは統計分析とCRO（コンバージョン率最適化）の専門家です。

# 与えられたデータ
ランディングページのA/Bテスト結果（2週間実施）:

**バージョンA（コントロール）**
- 訪問者数: 10,000
- コンバージョン数: 250
- コンバージョン率: 2.5%
- 平均購入額: 5,000円
- 総売上: 1,250,000円

**バージョンB（変更版）**
- 訪問者数: 10,000
- コンバージョン数: 320
- コンバージョン率: 3.2%
- 平均購入額: 4,800円
- 総売上: 1,536,000円

**変更内容**:
- ヘッドラインの変更
- CTAボタンの色を緑から赤に変更
- 価格表示の簡略化

# 分析タスク

1. **統計的有意性の評価**
   - コンバージョン率の差は統計的に有意か（95%信頼区間で評価）
   - サンプルサイズは十分か

2. **ビジネスインパクト**
   - 月間での売上増加額の推定（月間訪問者30万人と仮定）
   - ROI分析（実装コスト50万円と仮定）

3. **詳細分析**
   - 平均購入額が下がった理由の仮説（3つ）
   - セグメント別の影響（デバイス、時間帯、流入元などで推測）

4. **次のステップ**
   - この結果から得られる学び
   - 次のテストアイデア（5つ）
   - ロールアウト戦略（段階的展開 vs 全面展開）

# 出力形式
1. **判定**: BをロールアウトすべきかYes/No、理由
2. **統計分析結果**: 詳細な数値と信頼区間
3. **ビジネス分析**: 売上とROIの詳細計算
4. **リスクと考慮事項**: 見落としている可能性がある点
5. **推奨アクション**: 次の30日間で行うべきこと
```

## 6. ソーシャルメディア分析

```markdown
# 役割
あなたはソーシャルメディアアナリストです。

# 与えられたデータ
Instagram アカウントの月間パフォーマンス（2024年3月）:

**全体指標**
- フォロワー数: 15,000 (月初) → 16,500 (月末)
- 投稿数: 20
- 総インプレッション: 250,000
- 総リーチ: 120,000
- プロフィール訪問: 8,500
- ウェブサイトクリック: 1,200

**投稿タイプ別平均**
| タイプ | 投稿数 | 平均いいね | 平均コメント | 平均保存 | 平均シェア |
|--------|--------|----------|------------|---------|----------|
| 写真 | 8 | 450 | 15 | 30 | 8 |
| カルーセル | 7 | 650 | 25 | 80 | 15 |
| リール | 5 | 1,200 | 40 | 120 | 35 |

# 分析タスク

1. **エンゲージメント分析**
   - エンゲージメント率の計算（投稿タイプ別）
   - 最もパフォーマンスの高いコンテンツタイプ
   - フォロワー成長率の評価

2. **コンテンツ戦略評価**
   - 各コンテンツタイプの強みと弱み
   - 保存率とシェア率から見る価値提供度

3. **リーチとインプレッション**
   - リーチ/フォロワー比率の評価
   - インプレッション/リーチ比率（フリークエンシー）

4. **コンバージョンファネル**
   - プロフィール訪問率
   - ウェブサイトクリック率
   - コンバージョン改善ポイント

# 出力形式
1. **パフォーマンスサマリー** (150文字)
2. **詳細分析**: 各指標の評価とベンチマーク（一般的な業界平均と比較）
3. **コンテンツ戦略提案**:
   - 投稿頻度の最適化
   - 投稿タイプの配分
   - 投稿時間の最適化（仮説ベース）
4. **成長戦略**: フォロワー2万人達成のための3ヶ月プラン
5. **KPI設定**: 次月で追うべき5つの指標と目標値
```

---

これらの例は、データの文脈、分析の観点、期待する出力形式を明確に示すことで、AIから洞察に富んだ分析結果を引き出すプロンプトの好例です。
