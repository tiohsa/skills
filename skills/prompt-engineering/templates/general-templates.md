# 汎用プロンプトテンプレート

## 基本構造テンプレート

```markdown
# 役割
あなたは[専門分野]の[役割/専門家]です。

# コンテキスト
[背景情報や状況説明]

# タスク
[具体的な依頼内容]

# 制約条件
- [制約1]
- [制約2]
- [制約3]

# 出力形式
[期待する出力の形式やフォーマット]

# 例（オプション）
[参考例や期待する出力のサンプル]
```

## コード生成テンプレート

```markdown
# 役割
あなたは経験豊富な[プログラミング言語]開発者です。

# タスク
以下の要件を満たすコードを書いてください：

## 機能要件
- 機能: [機能の説明]
- 入力: [入力の型、形式、例]
- 出力: [出力の型、形式、例]
- エッジケース: [考慮すべき特殊ケース]

## 技術要件
- 言語/フレームワーク: [使用する技術スタック]
- パフォーマンス: [要求されるパフォーマンス]
- 依存関係: [使用可能/禁止のライブラリ]

## コーディング規約
- [命名規則]
- [コメントスタイル]
- [エラーハンドリングの方針]

## 期待する出力
1. 完全に動作するコード
2. 使用例/デモコード
3. テストケース（最低3つ）
4. 計算量分析（時間・空間）
5. 改善の余地があれば提案
```

## データ分析テンプレート

```markdown
# 役割
あなたはデータサイエンティスト/アナリストです。

# 与えられたデータ
[データの説明、フォーマット、サンプル]

## データの特徴
- データソース: [データの出所]
- データ期間: [対象期間]
- データサイズ: [レコード数など]
- 重要な前提: [データに関する重要な情報]

# 分析タスク
以下の観点でデータを分析してください：

1. **[分析観点1]**
   - [具体的な質問や調査項目]

2. **[分析観点2]**
   - [具体的な質問や調査項目]

3. **[分析観点3]**
   - [具体的な質問や調査項目]

# 出力形式
1. **分析サマリー**: 主要な発見を3-5点で簡潔に
2. **詳細分析**: 各観点の詳細な分析結果
3. **ビジュアライゼーション提案**: 適切なグラフやチャートの種類
4. **インサイトと推奨事項**: データから得られる洞察と具体的なアクション
5. **追加で必要なデータ**: さらなる分析に必要な情報
```

## 問題解決テンプレート

```markdown
# 役割
あなたは[分野]の問題解決の専門家です。

# 問題の定義
[直面している問題を明確に記述]

## 現状
- [現在の状況]
- [既に試したこと]
- [利用可能なリソース]

## 制約条件
- [時間的制約]
- [予算的制約]
- [技術的制約]
- [その他の制限]

## 目標
- [達成したい状態]
- [成功の測定基準]

# タスク
以下のステップで問題を分析し、解決策を提案してください：

1. **問題の分析**: 根本原因を特定
2. **解決策の立案**: 複数のアプローチを提案（最低3つ）
3. **評価**: 各解決策の長所・短所、実現可能性を評価
4. **推奨**: 最適な解決策を選択し、理由を説明
5. **実行計画**: ステップバイステップの実装プラン

# 出力形式
1. **問題分析サマリー** (200文字)
2. **解決策の比較表**: 各案の評価
3. **推奨解決策**: 詳細な説明と実行プラン
4. **リスクと対策**: 想定されるリスクと緩和策
5. **成功指標**: 進捗を測定するKPI
```

## レビュー・評価テンプレート

```markdown
# 役割
あなたは[分野]の専門レビュアー/評価者です。

# レビュー対象
[レビューする対象物の説明または添付]

## 評価基準
以下の観点で評価してください：

1. **[評価観点1]** (重要度: 高/中/低)
   - [具体的な評価ポイント]

2. **[評価観点2]** (重要度: 高/中/低)
   - [具体的な評価ポイント]

3. **[評価観点3]** (重要度: 高/中/低)
   - [具体的な評価ポイント]

## コンテキスト
- 目的: [レビュー対象の目的]
- 対象ユーザー: [想定ユーザー]
- 比較基準: [ベンチマークや競合]

# 出力形式
1. **総合評価**: スコア（10点満点）と一言サマリー
2. **詳細評価**: 各観点の評価とスコア
3. **強み**: 優れている点（3-5点）
4. **改善点**: 問題点と改善提案（優先順位付き）
5. **推奨アクション**: 次にすべきこと
```

## リサーチテンプレート

```markdown
# 役割
あなたは[分野]のリサーチャーです。

# リサーチ目的
[調査の目的と背景]

## リサーチクエスチョン
主要な問い:
- [メインの問い]

副次的な問い:
- [サブクエスチョン1]
- [サブクエスチョン2]

## スコープ
- 対象範囲: [調査範囲]
- 期間: [対象期間]
- 地域: [対象地域]
- セグメント: [対象セグメント]

## 情報源
- [利用可能な情報源や制約]

# タスク
包括的なリサーチを実施し、以下を提供してください：

1. **背景調査**: 関連する基礎知識と現状
2. **主要な発見**: リサーチクエスチョンへの回答
3. **データと証拠**: 発見を裏付ける情報
4. **トレンドとパターン**: 重要な傾向の分析
5. **ギャップと制約**: 情報の欠落と調査の限界

# 出力形式
1. **エグゼクティブサマリー** (300文字)
2. **詳細リサーチレポート**: セクション分けされた包括的な報告
3. **キーファインディング**: 最重要発見5-7点
4. **インプリケーション**: 発見がもたらす影響
5. **次のステップ**: さらなる調査の提案
```

## 比較・選択テンプレート

```markdown
# 役割
あなたは[分野]の意思決定支援の専門家です。

# 比較対象
以下の選択肢を比較評価してください：

## オプション1: [名前]
- [特徴1]
- [特徴2]

## オプション2: [名前]
- [特徴1]
- [特徴2]

## オプション3: [名前]
- [特徴1]
- [特徴2]

## 評価基準
重要度順に:
1. [基準1] (重み: X%)
2. [基準2] (重み: X%)
3. [基準3] (重み: X%)

## コンテキスト
- 使用目的: [利用シーン]
- 予算: [予算制約]
- その他の制約: [考慮すべき要素]

# タスク
各オプションを評価基準に基づいて比較し、推奨を提供してください。

# 出力形式
1. **比較表**: 各オプションを評価基準で比較
2. **スコアリング**: 各オプションの総合スコア
3. **詳細分析**: 各オプションの長所・短所
4. **推奨**: 最適な選択肢と理由
5. **状況別の推奨**: 異なるシナリオでの最適解
```

これらのテンプレートをベースに、自分の具体的なニーズに合わせてカスタマイズしてください。
