# frontend-design

## 概要
`frontend-design` は、Web画面、コンポーネント、アプリケーション、ランディングページなどを、目的や対象ユーザーに合った高品質なUIとして実装するための Skill です。汎用的なAI風デザインを避け、明確な美的方向性、タイポグラフィ、配色、モーション、空間設計まで踏み込んで仕上げます。

## 使う場面
- Web UI、React コンポーネント、HTML/CSS レイアウトを作りたい。
- 既存画面の見た目や体験品質を改善したい。
- ランディングページ、ダッシュボード、ツール、ポスターなどのビジュアル表現を作りたい。
- 目的やブランドに合った、記憶に残るUIデザインを具体化したい。

## 使わない場面
- 見た目や体験設計を伴わない純粋なバックエンド作業。
- 既存デザインシステムに従うだけで、独自のビジュアル検討が不要な小変更。
- デザインよりも障害調査、テスト自動化、MCP実装などが主目的の作業。

## 実行フロー
1. ユーザー、目的、制約、実装対象の画面やコンポーネントを確認する。
2. UIのトーンと美的方向性を明確に決める。
3. タイポグラフィ、配色、余白、モーション、背景表現を一貫した方針で設計する。
4. HTML/CSS/JS、React、Vue など指定環境に合わせて動くUIを実装する。
5. レスポンシブ表示、文字の収まり、インタラクション、視覚的な完成度を確認する。

## 生成・更新する主な成果物
- WebページやUIコンポーネントの実装コード
- CSS、アニメーション、レイアウト、テーマ変数
- 既存UIのデザイン改善差分
- 必要に応じたスクリーンショット確認や視覚検証結果

## 注意点
- `Inter`、`Roboto`、`Arial`、紫系グラデーションなどの定番的で汎用的なAI風表現に寄せない。
- デザインの強さではなく、意図の明確さと実行精度を優先する。
- 最大主義でも最小主義でも、複雑さは選んだ美的方向性に合わせる。
- ボタンやカード内のテキストがはみ出さないよう、実際の表示を確認する。
